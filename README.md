## 手机操作

第一部分使用固定在屏幕底部的“上一幅／选画／下一幅”。选画是独立全屏缩略图目录，可按名称、CR、收藏机构、年代和收录范围筛选，点图后返回作品；不再把长列表塞进正文上方的小滚动区域。画面支持左右轻扫，正常纵向滚动与双指动作不会被当作换画。

点图进入大图。关闭后返回原来的阅读位置，可切换适合屏幕／放大查看及作品资料。原有10×10定位网格和已有观察区坐标保留，没有添加虚构的绘画细节。

第二部分与图谱共用入口，提供固定章节目录、前后章节、三档字号、可点开的配图、四组比较及手机卡片式索引表格。点正文作品编号会打开对应图像，不强行跳离文章。

## 缺图与离线阅读

两部分都从本站的 `images/` 读取图片，不再依赖外部图床或短期私有 raw 链接。加载失败会明确提示并提供重试。此修复不代表所有参考图已经升级为高清原图：页面显示文件真实像素，不通过生成式放大补造细节。

网页的“更多 → 保存完整离线版（含图片）”会把58件作品图片、两部分正文、样式与脚本内嵌进一个HTML文件。必须全部图片取得成功才输出，避免再生成只有文字的“不完整离线版”。分享时转发HTML文件本身；文献链接仍需网络。

维护者也可运行：

```sh
python -m pip install Pillow
python scripts/package_mobile.py
```

输出在 `research-output/`。旧的 `scripts/package_research.py` 命令兼容同一完整打包方式。GitHub Actions 的 `Validate mobile site and package offline edition` 成功后会提供 `bacon-papal-mobile-edition` 文件包；只有成功运行才代表该次真实图片与浏览器测试已经完成。

## 运行与测试

```sh
python -m http.server 8000 --directory docs
```

无前端构建依赖或第三方浏览器脚本。维护时请将 `docs/` 和 `dist/` 保持同步。

验证脚本检查58个独立CR、全部图片解码与哈希、报告配图及编号链接、观察区坐标。浏览器脚本覆盖Chromium／WebKit及320、375、390、430、768、1440像素宽度，检查选画、前后切换、目录、关闭大图返回位置、全部图片、旧链接和离线零网络载图。详情及本次本地测试的限制见 [QA记录](QA/mobile-v2.md)。
