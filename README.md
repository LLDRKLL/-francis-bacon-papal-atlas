# Francis Bacon — Papal Atlas / 培根的教皇

中文作品研究网页：58件记录（46件教皇主题、12件边界与关联作品），约1946—1971年，含1件已毁作品。

## 使用

`python -m http.server 8000 --directory dist`，然后打开本地8000端口。

无需打包与前端依赖。`dist/` 可直接部署为静态网站；数据及解读在 `dist/data.json`。画作参考图均为本地图像，作品原条目和研究文献在每张作品旁可追溯。

## 功能

- 按年代浏览；按题名、年份、CR编号、收藏机构查找。
- 区分教皇主题与边界／关联作品。
- 每件作品的材料、尺寸、收藏地点、创作与系列位置、图像观察及关联解读。
- 所有作品有归一化10×10定位网格；四件重点作品有可开关的文字区域定位。
- 图片保留比例，不裁掉原作；可独立打开大图。

## 编目边界

以The Estate of Francis Bacon在线Catalogue Raisonné的作品记录为基本标识，不将Pope字样作为唯一收录标准。核查1940—1970年代目录标题，收录1953年八幅、1961年六幅完整编号组，以及Head VI、Figure with Meat、Figure Sitting、Seated Figure 1960等明确关联的图像。另列边界头部、正装肖像及Painting 1946。

“所有”无法扩展成对未编目佚失作品、碎片及尚未识别作品的保证。页面明确公开这一范围，不冒称官方完整专题目录。候选集及排除项保留在 `catalogue-candidates.json`；最终收录及逐件图像观察在 `curate.py`。58件图像均经接触表查看。

收藏记录主要来自在线CR，是有日期背景的公开记录，不是实时所有权查询，也不意味着当前展出。私人收藏没有虚构街道地址。55-14在线条目旧写下落不明，以遗产管理机构2017年重新现身新闻补充说明；63-14以SFMOMA藏品记录更新机构名称。

## 维护与验证

`collect.py` 抽取官方编目字段；`get_images.py` 下载参考图并生成检查用接触表（需要Pillow）；`curate.py` 生成最终有边界的资料集。

交付前检查：JavaScript语法；58个CR编号唯一性；逐件必需字段；58张本地图片解码；区域坐标边界。未进行浏览器自动化测试。
